# V4 版本说明

## 更新内容

本版本基于 V3 进行了底盘控制参数优化，主要改进如下：

### ✅ 已优化
- **前进/后退起步偏移大幅改善**：通过引入非对称起步 Kick 机制和精细的物理死区补偿校准参数，消除了 V3 中前进和后退时因左右轮静摩擦差异导致的严重跑偏问题。
- **渐进式速度斜坡（Soft Start / Soft Stop）**：目标速度以 `0.04f` 步长平滑过渡，避免瞬态阶跃冲击。
- **OLED 实时双轮速度遥测仪表盘**：屏幕上同时显示左右轮的设定目标速度 (T) 与实际编码器反馈速度 (A)，便于实时诊断轮速匹配状态。
- **上电锁定机制**：上电后电机保持停止，需按下 KEY1 解锁手势控制后才响应运动指令。

### ⚠️ 已知问题
- **起步瞬间仍存在微小偏摆**：前进起步时仍有轻微的方向偏摆（幅度很小），后续版本将继续微调死区补偿参数以彻底消除。

### 🔧 关键参数（ctrl.c）
```c
// 死区补偿校准
#define DEADBAND_L_FWD   14.0f   // 左轮前进死区
#define DEADBAND_L_BWD  -54.0f   // 左轮后退死区
#define DEADBAND_R_FWD   58.0f   // 右轮前进死区
#define DEADBAND_R_BWD  -18.0f   // 右轮后退死区

// 非对称起步 Kick
#define KICK_L_FWD   1.0f       // 左轮前进 kick
#define KICK_R_FWD   1.3f       // 右轮前进 kick
#define KICK_BWD    -1.2f       // 后退 kick
```
